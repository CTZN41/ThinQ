## 검사

- 저장된 428개 모델명과 상세 Product 구조화 데이터의 모델명 전부 일치.
- 기존 스냅샷 파일 해시 전부 일치. 화면에서 한글이 깨져 보인 PowerShell 기본 디코딩과 달리 파일은 UTF-8 정상.
- 현재 공식 목록 전체 수: 세탁기 100, 오븐·전자레인지 36, 에어컨 301로 기존과 같음. 이번 감사는 전체 목록의 모든 상태를 재수집한 것은 아님.
- 품목당 2개, 총 6개 상세페이지 재조회 결과 전체 추출 스펙 값이 기존 저장본과 일치. 같은 파서를 사용한 회귀 대조이므로 모든 항목의 의미 정확성을 독립 검증한 것은 아님.
- 같은 에어컨 모델명 6종에 판매 식별자 15개가 있음. 최초 수집은 그중 대표 6개만 남겼으므로 9개 식별자별 상세가 누락되었음. 해당 15개는 same_model_variants.json으로 별도 수집.
- 최신 판매 제품용 별도 뷰: active_products.json. 기존 DB 대비 추가 판매 활성 모델: active_new_to_baseline.csv.

## 크롤러 수정

- 모델명만이 아니라 category + modelName + modelId로 키를 구성해 판매 식별자를 보존.
- 상세 제품명 검증을 부분 문자열 비교에서 정확한 model 또는 SKU 모델 부분 일치로 변경.
- 기본 재실행은 네트워크 재조회. 중단 작업 이어받기만 --resume 사용.

원본 428개 스냅샷은 보존한다. 기능 보유 정보와 코스별 온도·탈수 허용 조합, ThinQ API 제어 가능 여부는 별개다. 이번 결과를 곧바로 실제 제어 프로필로 해석하면 안 된다.
