# 세탁기·에어컨·오븐/전자레인지 상세 스펙

최종 사용 파일은 **공홈_상세스펙_전용.csv**와 **공홈_상세스펙_전용.json**입니다.

- 범위: 세탁기 105개, 에어컨 302개, 광파오븐·전자레인지 36개 = 443개 항목(모델 기준 434개).
- 필드: 카테고리, 모델명, 제품명, 상세스펙, 공식출처URL, 수집일(UTC).
- 공식 스펙 항목·값·설명을 보존하고, 점수·리뷰·추천·분석·가격·병합 메타데이터는 제외했습니다.
- 기존 자료만 있던 6개 모델도 공식 상세 페이지의 모델 식별과 스펙을 다시 확인했습니다.
- 같은 모델명의 판매 변형은 출처 URL로 구분합니다. 이 데이터는 현재 판매 중인 제품만의 목록이 아닙니다.
- API 제어 가능 여부나 앱 가상 제품 등록을 의미하지 않습니다.

이 폴더의 `products_merged.json`과 `세탁기_에어컨_오븐전자레인지_합본.csv`는 원문 보존용 이전 합본입니다. 상세 스펙만 필요하면 위 최종 사용 파일을 선택하세요.

## 다시 생성

저장소 루트에서:

```powershell
python data/lg_catalog_merged_2026-11-17/code/export_three_categories.py
python data/lg_catalog_merged_2026-11-17/code/export_official_specs.py
```

두 번째 명령은 최신 수집이 없는 기존 모델의 공식 페이지를 다시 조회합니다. 확인에 실패한 모델은 상세 스펙 전용 파일에서 제외하고 `official_specs_validation.json`에 남깁니다. 전체 크롤링과 병합 방법은 [크롤러 안내](../lg_catalog_merged_2026-11-17/README.md)를 참조하세요.
