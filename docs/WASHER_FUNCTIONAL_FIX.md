# 기능성 의류 분류 누락 수정

2026-11-17. 동일 Luna 모델로 수정 전후 실제 호출 검증.

## 재현

사용자의 ‘혼합 의류지만 기능성 위주, 탈수 약, 3~40도’ 문장과 ‘기능성 의류, 탈수 약, 30도’ 문장 모두 기존 purpose=null, 후보 없음이었다. 분류 enum과 합성 프로필에 기능성 의류가 없었다.

## 수정 결과

- 기능성 분류와 화면 선택지를 추가했다. 혼합 표현과 수온 원문도 별도 보존한다.
- 첫 문장은 functional, spin=low, temperature_description=3~40도 정도, temperature_c=null로 추출. 기능성 후보를 표시하되 정확한 수온은 확인한다.
- 두 번째 문장은 functional, spin=low, temperature_c=30으로 추출되어 기능성 후보 추천.
- 혼합 의류는 주로 언급된 의류 기준의 후보이며 모든 옷의 동시 세탁 적합성을 검증하지 않았음을 표시한다.
- 73개 단위 테스트 통과. 실제 호출 결과는 FUNCTIONAL_before.json / FUNCTIONAL_after.json에 보관.

## 실제 기능 범위

코스명 입력 없이도 의류 분류에 맞는 코스를 고른다. 온도·헹굼·탈수는 명시된 경험을 유지하거나 사용자가 허용한 경우 합성 프로필 범위로 조정한다. 언급하지 않은 헹굼 횟수 등을 생성하지 않는다. 스팀·추가 헹굼·건조 등 새로운 기능을 사용 목적에 따라 발굴하고 효과까지 검증하는 추천 엔진은 아직 아니다.

추가된 기능성 코스의 20/30/40도, 약/중 탈수, 50분 등은 테스트용 합성 가정이다. 실제 LG 기능성 코스의 사양·혼합 세탁 적합성을 의미하지 않는다. 실제 제어 프로필에 사용하면 안 된다.
