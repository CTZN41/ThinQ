# 실제 연결 및 한국어 UI 재설계

검증일: 2026-11-17

## 후속 변경: 한 번에 설정 적용

사용자 요청에 따라 별도 미리보기·확인 창과 설정별 버튼을 제거했다. 변경한 항목만 모아서 하단의 `설정 적용` 버튼으로 즉시 전송한다. 원래 값으로 되돌린 항목은 제외한다. 값이 비어 있거나 제약에 맞지 않으면 전송하지 않는다.

서버의 `/api/apply`는 전체 선택 항목을 검증한 뒤 순차 전송한다. 기기에서 원자적으로 한 번에 적용되는 트랜잭션은 아니며, 일부 실패 시 이미 전송한 설정은 되돌리지 않는다. 결과 불명확 시 나머지 전송을 중단하고 자동 재시도하지 않는다. 진행 중 중복 클릭을 막는다.

검증: 자동 테스트 38개 통과, 모의 제품의 온도·모드 일괄 적용 및 모바일 브라우저 검사 통과. LIVE 화면에서 제어 15개·통합 버튼·미리보기 창 제거 확인. 실제 제어 POST는 보내지 않았다. 서버를 재시작하여 새 기능을 반영했다.

아래 미리보기 방식 설명은 이전 구현 기록이다.

## 실행

- 실제 연결: http://127.0.0.1:8766
- 기존 `.env`의 PAT를 서버에서 읽으며 국가 코드는 KR이다. 토큰을 브라우저로 전달하지 않는다.
- VS Code 기본 실행 작업은 LIVE / KR (8766)이다. 8765는 별도의 모의 테스트 서버다.

## 구현

- `thinq_demo/static/index.html`, `style.css`, `app.js`를 변경했다.
- ThinQ 앱의 제품 카드 중심 구성을 참고하여 우리집 대시보드, 제품 선택, 전원·온도·모드 요약, 제어 화면을 구성했다. 공식 앱이 아닌 개인 개발 데모임을 표시했다.
- 제품 종류, 조회된 에어컨 제어 15개, 옵션, 현재 상태, 미리보기 및 결과를 한국어로 표시한다. 알 수 없는 항목은 원래 식별자를 함께 보존한다.
- 화면 표시만 번역하며 API 속성명·명령·열거값은 그대로 전달한다.
- 화씨·이중 온도는 고급 설정에 배치했다. 개발용 원본 정보는 접힌 영역에 보존했다.
- 변경 미리보기 후 별도 확인 버튼으로 전송한다. 미리보기에는 생성된 전체 명령을 표시한다.
- 제품 종류별 제어는 기존 공통 SDK 구조를 유지한다. 현재 실제 확인 범위는 계정에 등록된 에어컨 2대다.

## 검증 결과

- LIVE 서버에서 에어컨 2대의 목록·상태·지원 제어 조회 성공. 각각 제어 15개의 한국어 제목을 확인했다.
- 브라우저의 POWER_ON 등 실제 옵션값이 원래 API 값으로 유지됨을 확인했다.
- LIVE 검증 중 POST 요청은 0건이다. 물리적 작동 성공은 검증하지 않았다.
- 모의 서버에서 미리보기 → 확인 → 결과 반영, 오프라인 제품 차단, 미지원 제품 안내를 통과했다.
- 데스크톱 1440px 및 모바일 390px에서 화면 확인, 가로 넘침 및 JavaScript 오류 없음.
- `tests/browser_smoke.py`의 예상 문구를 한국어 결과 표시로 갱신했다.
- 화면 기록: `screenshots/live-desktop.png`, `screenshots/live-mobile.png`.

## 제한

프로필의 형식·제약 정보를 해석할 수 없는 속성은 제어에서 제외한다. 지원 제어가 표시되더라도 제품의 현재 모드·원격 제어 조건에 따라 실제 요청이 거절될 수 있다. 자동 조회는 페이지 진입·제품 선택·새로고침 시 수행한다.
