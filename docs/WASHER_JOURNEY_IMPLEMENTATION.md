# LIFEPRINT 세탁 경험 이어가기 — 구현 메모

## 사용자 화면 간소화

기본 화면은 경험 입력 → 추천 방법 → 선택 후 체험으로 정리했다. 저장한 경험, 조건 수정, 다른 방법, 저장, 피드백은 필요할 때 펼친다. JSON·결정 이력·API 설명은 사용자 화면에서 제거했다. 이력은 내부 데이터로 유지한다. 동률일 때는 후보를 함께 표시하고, 필수 정보가 빠졌을 때만 조건 입력을 펼친다. 데모 안내는 상단 배지와 하단 문장으로 유지한다.

저장 카드 불러오기, 세부 항목 기본 접힘, 모의 시작, 모바일 너비, JavaScript 오류 여부를 브라우저에서 확인했다. 화면 캡처는 `screenshots/washer-simple.png`다. 기존 전체 화면용 브라우저 테스트의 선택자는 이전 UI 기준이다.

## 구현 범위

`http://127.0.0.1:8769/washer.html`에서 모의 세탁기로 실행한다. 기존 실제 가전 제어 서버와 분리했다.

1. 구형 모델과 자연어 경험을 Luna가 구조화한다. 용도·수온·헹굼·탈수·시간의 종류와 범위를 추출한다.
2. 추가 답변은 같은 세션에 반영한다. 조건 변경 시 기존 후보 선택을 해제해 다시 확인하도록 한다.
3. 용도 일치 여부는 항상 제약으로 적용한다. 수온·헹굼·탈수는 사용자가 필수 유지 여부를 선택한다.
4. 변경을 허용한 값만 지원 범위로 조정하고 변경 전후를 표시한다. 설정 보존·시간 유사성·짧은 시간 중 우선순위를 고른다.
5. 추천과 실행 선택을 분리한다. 동률이면 임의로 추천하지 않으며, 사용자가 지원 후보를 선택하면 모의 시작이 가능하다.
6. 경험 카드는 이 PC의 `private/washer_cards.sqlite3`에 저장한다. 다시 불러올 때 현재 합성 프로필로 재검증한다. 같은 카드 재저장은 기존 카드를 갱신한다.
7. 피드백은 탈수 한 단계 변경을 제안할 수 있다. 자동 적용하지 않으며, 탈수가 필수 유지 조건이면 제안하지 않는다. 사용자가 반영한 뒤 다시 저장해야 카드에 남는다.

## 설계 이유

- LLM은 자연어 추출에만 사용한다. 추가 답변·후보 비교·카드 재사용·피드백 규칙은 Python에서 처리해 호출 비용과 변동성을 줄인다.
- 사용자가 말한 경험과 제품 설명서의 검증된 사양은 다르다. 모델명 입력만으로 구형 기기의 실제 코스 제약을 알고 있다고 간주하지 않는다.
- 시간은 전체 관찰 시간일 때만 비교한다. 예약 시간과 세탁 단계 시간은 전체 코스 시간과 비교하지 않는다.
- 사용자 만족 보고와 세탁 성능의 실험 검증은 구분한다. 피드백 조정은 원인을 확정하거나 개선을 보장하지 않는다.
- 양은 이번 비교 범위에서 제외한다.

## 파일과 데이터

- `washer_journey.py`: 세션, SQLite 카드, 명시적 선택, 피드백 제안·반영 이력.
- `washer_match.py`: 합성 프로필, 필수 조건 필터링, 선호 조건 조정, 후보 순위.
- `web.py`: MOCK 전용 `/api/washer/flow`, `/api/washer/cards`. 기존 동일 출처·CSRF 보호 적용.
- `washer.html`, `washer.js`: 추가 답변, 후보 카드, 저장·재사용, 피드백 화면.
- `tests/test_washer_journey.py`: 선택 전 실행 금지, 조건 변경, 제안 미자동적용, 재사용·중복 방지 검증.
- `tests/washer_journey_demo.py`: 유료 Luna 호출이 있는 별도 수동 브라우저 검증. 일반 단위 테스트에서 실행하지 않는다.

카드에는 구조화된 경험과 결정 이력을 저장하며 API 키는 저장하지 않는다. `private/`는 Git 제외 대상이다. 로컬 SQLite 자체를 암호화하지는 않는다.

## 검증 결과 (2026-11-17)

- 단위 테스트 61개 통과. 저장 연결이 닫히지 않던 문제를 수정하고 임시 DB 삭제까지 확인했다.
- 실제 Luna 분석부터 조건 변경, 후보 선택, 모의 시작, 피드백 제안·승인, 카드 저장 후 새로고침·재사용까지 브라우저 검증 통과.
- 별도 고정 입력 서버에서도 같은 흐름 검증. 390px 모바일 가로 넘침 및 JavaScript 오류 없음.
- 분석 재시도 중 1회 완료 화면에 도달하지 못했으며 이후 재실행은 통과했다. 외부 API의 상시 가용성을 보장하는 검증은 아니다.
- 캡처: `screenshots/washer-journey.png`, `screenshots/washer-journey-mobile.png`.

## 실제 제품 적용 전 남은 과제

신형 역할은 `LIFEPRINT-WASHER-DEMO-v1`이다. 코스·옵션·시간은 실제 LG 모델 사양이 아닌 합성 가정이다. 구형·신형의 공식 설명서에서 코스별 허용 옵션과 시간 조건을 검증한 뒤에만 실제 모델 프로필로 대체해야 한다. 현재는 실제 세탁기 명령 전송이나 결과 재현 검증을 하지 않는다.

기존 `washer_demo.py`, `washer_match_demo.py`는 이전 화면 단계의 기록이다. 현재 화면 검증에는 `washer_journey_demo.py`를 사용한다.
