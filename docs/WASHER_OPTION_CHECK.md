# 상대적 탈수 경험과 유지 옵션 검증

2026-11-17. 모델은 기존 Luna 유지. 실제 세탁기 명령은 전송하지 않았다.

## 변경

“탈수를 좀 쎄게 하니까 냄새가 덜 나고 잘 말랐다”는 표현을 상대적 변경(`spin_change=stronger`)과 사용자 관찰(`outcome`)로 분리한다. 최종 단계가 없으면 `spin=null`로 두고 약·중·강 단계를 확인한다. 확인 전에는 모의 시작도 막는다. 이 제한은 유지 옵션을 모두 해제해도 적용된다. 건조한 느낌으로 기계 건조 기능을 추론하지 않는다.

탈수 출력 스키마도 low/medium/high/null로 제한했다. 첫 검증의 명시적 단계 사례에서 ValueError가 발생했고, enum 제한을 추가한 뒤 전체 3개 사례가 통과했다. 첫 실패의 원시 응답을 보존하지 않았으므로 원인을 단정하지 않는다.

## 검증 결과

자연어 3개 사례: 단독 상대 표현, 기존 설정이 있는 상대 표현, ‘중에서 강 단계’가 명시된 표현 모두 최종 실행에서 통과했다. 결과는 `WASHER_RELATIVE_EVALUATION.json`에 보관한다.

자동 테스트 64개 통과. 그중 유지 옵션 3개의 모든 조합 8개 × 우선순위 3개 = 24개 조건을 검증했다.

기준: 일반 의류, 수온 40도, 헹굼 3회, 탈수 강, 관찰 시간 40~50분.

| 조건 변경 | 결과 |
|---|---|
| 모두 유지 | 일반 코스만 지원. 수온 40·헹굼 3·탈수 강 유지 |
| 수온 유지 해제 | 지원되는 40도를 바꿀 이유가 없어 그대로 유지 |
| 헹굼 유지 해제 | 단축 코스도 대안에 포함. 단축 선택 시 3→2 변경 표시 |
| 탈수 유지 해제 | 지원되는 강 단계를 그대로 유지 |
| 모두 해제 | 소재 제약은 유지. 우선순위와 변경 수에 따라 후보 정렬 |
| 상대적 탈수 단계 미확인 | 모든 옵션을 해제해도 실행 보류 |
| 울·강 탈수·모두 해제 | 울 코스만 후보. 지원되는 약 탈수로 조정되며 변경 표시 |

옵션 해제는 해당 기능을 끄는 의미가 아니라 ‘이 값은 변경해도 된다’는 의미다. 실제 세탁 결과, 냄새 감소 또는 건조 효과를 검증한 결과는 아니다.
