# 실제 계정 연결 확인

확인일: 2026-11-17 (Asia/Seoul)

- 사용자 요청으로 실제 모드를 실행했다. 국가 코드는 KR이다.
- 사용자가 `.env.example`에 저장한 PAT를 `.env`로 옮기고 예제 파일의 PAT는 비웠다. 토큰 원문은 문서나 출력에 남기지 않았다.
- LIVE 서버 주소: http://127.0.0.1:8766
- 실제 제품 목록 조회 성공: 에어컨 2대.
- 두 제품 모두 프로필 및 현재 상태 조회 성공.
- 두 제품 각각 SDK 기반 제어 항목 15개 생성. 이는 항목 생성 확인이며 실제 제어 성공이 아니다.
- 각 프로필에서 일반 해석기의 경고 1개가 확인되었다. 해석되지 않는 쓰기 속성은 일반 폼에 임의로 노출하지 않는다.
- 제어 API 요청 및 설정 변경은 하지 않았다.
- VS Code 기본 작업을 LIVE/KR/8766으로 변경했다. MOCK 작업도 유지한다.

기존 PHASE 문서의 PAT 미입력/실기 조회 미검증은 작성 당시 상태다. 이번 확인으로 실제 인증·목록·프로필·상태 조회가 검증되었고, 실제 제어 및 물리 동작 검증은 여전히 남아 있다.

서버가 이미 실행 중이면 링크로 접속하면 된다. 기본 작업을 다시 실행해 포트 사용 중 오류가 나면 기존 서버를 중복 실행하지 않는다. 이번 LIVE 서버 PID는 3064이며, 종료가 필요할 때 현재 프로세스 경로와 실행 인수를 먼저 확인한다.
