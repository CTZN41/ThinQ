# 추천 근거와 불확실성 개선

2026-11-17. Luna 모델 유지. 실제 가전 제어 없음.

## 반영 사항

- 수온·용도·상대적 탈수 단계가 미확정이면 후보가 있더라도 추천 배지를 부여하지 않는다.
- 추천 가능, 추가 확인 필요, 지원 후보 없음, 동률을 구분한다.
- 추천 이유는 LLM 자유 서술 대신 실제 필터링·순위 규칙에서 생성한다. 유일한 지원 후보인지, 설정 변경을 최소화했는지, 시간 우선인지 설명한다.
- 명시되지 않은 헹굼·탈수는 미지정 상태를 표시한다. 성능 또는 냄새 개선을 보장하지 않는다.
- RPM과 약·중·강의 모델별 대응 자료가 없으면 임의로 변환하지 않는다. 사용자가 사용할 단계를 선택하기 전 모의 실행을 보류한다.
- 정정·부정·불명확한 선택지·혼합 소재의 추출 지침을 보완했다.

## 확인한 결과

단위 테스트 70개 통과. 실제 Luna 추가 평가 8건이 해당 실행에서 모두 통과했다.

| 사례 | 기대·관찰 결과 |
|---|---|
| 40도가 아니라 30도 | 최종 30도 |
| 30도인지 40도인지 모르겠다 | 수온 미정, 추천 보류 |
| 강이 아니라 약 | 최종 약 |
| 2시간 뒤 종료 예약 | 예약 시간으로 구분, 전체 시간 비교 제외 |
| 울과 수건 혼합 | 용도 미정, 한 소재로 임의 확정하지 않음 |
| 1200RPM | 숫자 보존, 강 단계로 임의 변환하지 않음 |
| 냄새 없고 뽀송, 설정 모름 | 관찰만 보존, 수온·탈수 추측하지 않음 |
| 울 60도·강 | 데모 지원 제약 불일치로 추천 없음 |

원시 구조화 결과: `WASHER_EXTENDED_EVALUATION.json`. 실행: `python -m tests.washer_extended_live` (유료 API 호출).

## 해석 범위

8건은 고정된 회귀 사례이며 전체 자연어 정확도 100%라는 의미가 아니다. 소재별 코스·시간은 합성 프로필이다. 실제 모델 설명서의 코스별 옵션 조합과 가전 실험을 확보하기 전에는 세탁 결과의 동등성을 확정할 수 없다. 화면의 추천은 현재 입력과 데모 제약에 대한 추천이다.
