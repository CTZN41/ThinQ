# 세탁 경험 비교 및 가상 실행 구현

2026-11-17. 모델 gpt-6-luna 유지. 화면: http://127.0.0.1:8769/washer.html

## 역할과 근거

구형 모델 후보 3종은 경험의 출처를 지정한다. 전체 구형 설명서 제약이 로딩된 것은 아니므로 모델명만 바뀌었다고 다른 물리 성능을 추정하지 않는다.

신형 역할은 **LIFEPRINT 가상 세탁기 v1**로 분리했다. 일반/단축/울/섬세/수건 코스의 온도·헹굼·탈수·시간은 코드에 명시한 데모 가정이다. LG FX25GFG의 검증된 사양으로 표시하지 않는다. 실제 모델 프로필을 확보하면 동일 비교기에 넣을 수 있다.

## 비교 절차

1. Luna는 명시된 코스·용도·수온·시간 종류와 범위·헹굼·탈수·결과 선호를 추출한다. 세탁물 양은 제외한다.
2. 서버가 용도와 수온·명시 옵션의 모든 조건을 만족하는 코스만 남긴다.
3. 전체 관찰 소요 시간일 때만, 후보의 가정 시간과 이전 시간 범위 사이의 최단 거리로 순위를 정한다. 단계 시간·예약 시간은 비교하지 않는다.
4. 최상위 동률이면 보류한다. 임의 기본 수온을 만들지 않는다. 미지정 헹굼·탈수는 null로 유지한다.
5. 추천과 제약이 확정되면 단일 사용·10분 만료 토큰으로 가상 설정 및 시작 상태만 반환한다. 실제 기기 호출, 실제 진행 시간 또는 물리적 세탁 결과 시뮬레이션은 없다.

## 화면 검증

- 일반 면 의류 / 40℃ / 전체 40~50분: 35분·55분 후보가 각각 5분 차이 → 동률 보류.
- 여기에 헹굼 3회 명시: 데모 단축 코스는 3회 미지원이라 제외 → 일반 코스 55분 추천.
- 수온 40℃와 헹굼 3회 보존, 예상 시간 차이 5분 표시, 가상 시작 상태 전환 확인.
- 테스트 55개 통과. 실제 Luna 호출 2건을 포함한 브라우저 시나리오 통과. 모바일 390px 가로 넘침 및 JS 오류 없음.
- 브라우저는 결과 화면을 열린 상태로 유지했다. 캡처: `screenshots/washer-match-simulation.png`.

## 파일

- `thinq_demo/washer.py`: 경험 추출·토큰·모의 시작.

- `thinq_demo/static/washer.html`, `washer.js`: 모델 선택·비교·근거·추가 질문·모의 실행.
